ours-blanc Drum Kit for R36S

使い方
1. この zip を展開し、中の ports フォルダの中身を SD カードの EASYROMS/ports/ にコピー
2. R36S のメニュー →「Ports」→「Drum Kit」を起動（SELECT + START で終了）

ボタン
  B キック / A スネア / Y クローズドハット / X オープンハット
  十字キー 上・左・下 タム 1〜3 / 右 クラップ / L2 クラッシュ / L3 ライド
  L1 再生・停止 / R1 ループ録音 ON・OFF（長押しでループをクリア）
  R2 ステップシーケンサー / START メトロノーム ON・OFF
シーケンサー
  十字キー カーソル / A ステップ ON・OFF / B 試聴 / X・Y テンポ ± / L2 録音のクオンタイズ ON・OFF / R2 パッドに戻る
ループは 4/4 拍子で 2 小節。録音したフレーズとシーケンサーは同じループを共有し、自動で保存されます。
起動の記録は EASYROMS/ports/drumkit/log.txt に残ります。
